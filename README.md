This repository contains three different tasks performed in Java using the MapReduce Framework in ApacheSpark:
1. G17HW1: Corresponds to a simple implementation of the K-means clustering algorithm Lloyd's.
2. G17HW2: It's a variant of the Lloyd's algorithm with a Fair Objective Function.
3. G17HW3: An streaming task that uses Count-Min Sketch and Count Sketch to compute the frequency of the elements.

The tasks were tested locally using the "uber_small" dataset mainly for debugging purposes, and later they run on the University's cluster to test their performance on big datasets.
